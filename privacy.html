Privacy

Local-only by design.

Codex Quota Calendar is a macOS menu bar utility. It does not operate a server and does not collect analytics.

Personal informationNot collected by this app
AnalyticsNone
Third-party trackersNone
Auth tokenStored only on your Mac
Quota samplesSmall local rolling history
NetworkOnly for the quota data the app displays

The app may read local Codex authentication data so it can query usage information for display. That credential is not uploaded to any developer-owned service.

本应用不会把你的授权信息、用量记录或账号信息上传到开发者服务器。历史记录只在本机保存，并且限制大小。
